# **Exercícios de Java**

**Básico**

**1. Olá Mundo personalizado**

- Peça o nome do usuário
- Exiba: `Olá, [nome]! Seja bem-vindo.`

**2. Soma de dois números**

- Peça dois números ao usuário
- Mostre a soma deles

**3. Número par ou ímpar**

- Peça um número
- Informe se ele é **par ou ímpar**

**Intermediário**

**4. Média de notas**

- Peça 3 notas
- Calcule a média
- Exiba:
  - Aprovado (>= 7)
  - Recuperação (>= 5 e < 7)
  - Reprovado (< 5)

**5. Tabuada**

- Peça um número
- Mostre a tabuada dele (1 a 10)

**6. Contagem regressiva**

- Peça um número
- Faça uma contagem regressiva até 0 usando `while`

**Estruturas**

**7. Maior número**

- Peça 5 números
- Mostre o maior deles

**8. Sistema simples de login**

- Crie um usuário e senha fixos no código
- Peça para o usuário digitar
- Mostre:
  - "Login correto"
  - "Login inválido"

**Avançado**

**9. Calculadora**

- Peça dois números
- Peça a operação (+, -, \*, /)
- Mostre o resultado

**10. Lista de nomes (Array)**

- Crie um array com 5 nomes
- Mostre todos eles usando `for`

**Desafio**

**11. Sistema de cadastro**

- Permita cadastrar 3 usuários (nome e idade)
- Depois mostre todos os cadastrados
